# 历史记录

一个无需构建即可安装的 Manifest V3 Chrome 扩展，用更清晰的时间线和网站分组替换默认的 `chrome://history/` 页面。

## 当前功能

- 搜索标题、网址和网站
- 默认查看今天，并可切换最近 3 天、7 天、30 天、90 天或全部历史
- 支持按时间平铺记录或按域名折叠分组，默认按时间展示
- 相同域名自动合并为可折叠分组，默认折叠
- 打开历史页面、删除单个网址和批量删除
- 使用接近 Chrome 默认历史记录的扩展图标
- 点击浏览器工具栏扩展图标打开历史记录

所有历史数据均通过 Chrome 官方 API 在浏览器本地读取和处理，不会上传到服务器。

## 安装

需要 Chrome 115 或更新版本。先克隆仓库，或通过 GitHub 的 **Code → Download ZIP** 下载并解压。

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的项目文件夹。
5. Chrome 出现历史记录权限提示时确认授权。
6. 打开 `chrome://history/`，即可进入新的历史记录页面。

可以在扩展菜单中将“历史记录”固定到工具栏，以后点击图标即可打开。

## 更新本地版本

修改文件后，进入 `chrome://extensions/`，在扩展卡片上点击“重新加载”，然后刷新历史记录页面。

## 恢复 Chrome 默认历史记录页面

进入 `chrome://extensions/`，关闭或移除“历史记录”。再次打开 `chrome://history/` 就会恢复 Chrome 默认页面。

## 权限说明

- `history`：读取、搜索和删除 Chrome 历史记录，是核心功能必需权限
- `favicon`：读取历史页面对应的网站图标

扩展没有申请任意网站访问权限，也没有网络请求或远程数据存储。

## 开发与提交

项目使用原生 HTML、CSS 和 JavaScript，无需安装依赖或执行构建。每次查询最多显示 5000 个页面；删除操作会移除对应网址的全部访问记录。
